# SYNTRAC Brand Guidelines

**Product descriptor:** System Intelligence & Activity Tracking  
**Tagline:** See Everything. Understand Anything.  
**Positioning:** A local-first workstation observability and behavioral security platform.

## Brand personality
- **Observant:** Makes complex system activity understandable.
- **Grounded:** Calm, clear, and trustworthy rather than alarmist.
- **Intelligent:** Connects events into patterns and useful explanations.
- **Respectful:** Local-first by default, transparent about collection.

## Visual direction
A premium, nature-inspired identity. Use warm cream and sand for brand surfaces and documentation; use charcoal as the primary application canvas. Forest green and sage provide the signature identity. Clay is a restrained highlight for emphasis and warning-adjacent accents. Reserve conventional red for critical security states.

## Typography
- **Primary:** Inter. Fallback: Segoe UI, Arial, sans-serif.
- **Headings:** Semibold / bold; use compact tracking.
- **Body:** Regular; prioritize legibility at 13–15 px in dense data views.
- **Telemetry values:** Tabular numerals (`font-variant-numeric: tabular-nums`).

## Logo usage
- Use the horizontal logo on splash screens, about pages, and marketing materials.
- Use the shield mark for application icons, tray icon, and compact navigation.
- On dark backgrounds use `syntrac-mark-light.svg`.
- Maintain clear space around the mark equal to at least 15% of its width.
- Do not stretch, rotate, add glow effects, or substitute arbitrary colors.

## UI principles
1. Calm by default; reserve strong color for meaningful state changes.
2. Pair every alert color with a label or icon; never communicate severity by color alone.
3. Show provenance and context for security findings: what was observed, when, and why it matters.
4. Distinguish **unusual** from **malicious**. An anomaly is an investigation lead, not a verdict.
5. Prefer progressive disclosure: summary first, drill-down details on demand.
6. Keep monitoring status and data freshness visible.

## Component conventions
- Cards: charcoal raised surfaces with subtle warm-gray borders.
- Primary action: forest green.
- Secondary action: slate/transparent.
- Warning: amber; critical: muted red; informational: blue-gray.
- Charts: sage for baseline, clay for comparison, cream for labels; use line styles or markers in addition to color.
- Tables: compact rows, clear column alignment, visible hover state, and persistent filter controls.

## Voice and terminology
Use direct, calm language: “New destination observed” rather than “Threat detected” unless threat intelligence confirms it. Prefer “Investigate,” “Review,” and “Learn more” over alarmist calls to action.
